# zindulka.github.io

Personal website of Tim Zindulka, published with GitHub Pages at https://zindulka.github.io/.

It is plain HTML and CSS with no build step. Edit `index.html` (content) or `style.css` (design), then commit and push to `main`. The live site updates within a minute or two.

- `images/portrait.jpg`: portrait, 640 × 640 px
- `fonts/`: Schibsted Grotesk, self-hosted so the site makes no third-party requests (SIL Open Font License, see `fonts/OFL.txt`)
- `favicon.svg`: browser tab icon
